GRILLIO

GRILLIO Burger

GRILLIO یک وب‌سایت با محوریت فست‌فود است که با ترکیب طراحی مدرن، جلوه‌های سه‌بعدی و امکانات تعاملی، تجربه‌ای متفاوت از حضور در یک وب‌سایت غذایی را به نمایش می‌گذارد

معرفی پروژه

GRILLIO با هدف ایجاد یک تجربه دیجیتال متفاوت برای یک مجموعه فست‌فود طراحی و توسعه داده شده است. در این پروژه تلاش شده است وب‌سایت از یک صفحه معرفی ساده فراتر برود و فضایی پویا، جذاب و تعاملی برای کاربران ایجاد کند

هویت بصری پروژه بر پایه رنگ‌های تیره، جزئیات گرم و طراحی مدرن شکل گرفته است تا حس و حال یک برند غذایی امروزی را منتقل کند

طراحی و تجربه کاربری

در طراحی GRILLIO توجه ویژه‌ای به ترکیب رنگ‌ها، تایپوگرافی، چیدمان عناصر و حرکت‌های بصری شده است. ساختار صفحات به‌گونه‌ای طراحی شده تا کاربران بتوانند به‌راحتی میان بخش‌های مختلف سایت حرکت کنند و به اطلاعات موردنظرشان دسترسی داشته باشند

همچنین طراحی واکنش‌گرا باعث می‌شود صفحات وب‌سایت در اندازه‌های مختلف نمایشگر، از دسکتاپ تا موبایل، قابل استفاده باشند

تجربه سه‌بعدی و تعامل

یکی از بخش‌های شاخص این پروژه، استفاده از مدل سه‌بعدی برگر در صفحه اصلی است. این بخش با کمک کتابخانه Three.js پیاده‌سازی شده و به وب‌سایت جلوه‌ای پویا و متفاوت می‌دهد

استفاده از عناصر متحرک و تعاملات بصری در کنار ساختار اصلی صفحات، باعث شده تجربه کار با سایت از حالت کاملاً ایستا خارج شود

صفحات و امکانات وب‌سایت

GRILLIO شامل بخش‌های مختلفی است که هرکدام بخشی از مسیر کاربر در وب‌سایت را پوشش می‌دهند؛ از آشنایی با مجموعه و مشاهده منو گرفته تا بررسی سبد خرید و مشاهده وضعیت نمایشی سفارش

تکنولوژی و توسعه

این پروژه با استفاده از HTML، CSS و JavaScript توسعه داده شده است. برای پیاده‌سازی بخش سه‌بعدی و نمایش مدل برگر نیز از کتابخانه Three.js استفاده شده است.

ساختار پروژه به‌صورت چندصفحه‌ای طراحی شده و شامل صفحات اصلی، منو، درباره ما، سبد خرید و پیگیری سفارش است

ویژگی‌های پروژه

  • طراحی مدرن با هویت بصری اختصاصی
  • نمایش مدل سه‌بعدی برگر با Three.js
  • منوی تعاملی و صفحات چندگانه
  • سبد خرید و فرایند نمایشی ثبت سفارش
  • صفحه نمایشی پیگیری سفارش
  • طراحی واکنش‌گرا برای موبایل و دسکتاپ
